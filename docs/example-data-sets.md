# Example JSON data sets

These files show the shape of data the website can consume later from Google Drive, Google Sheets, My Maps, Apps Script, agent skills or cron jobs.

## Public map points

`data/example-public-map-points.json`

Use this for public landmarks, access points and meeting places imported from a KMZ or Google My Maps layer.

Do not include private fishing spots, live team locations, member addresses or precise event routes.

## Field story export

`data/example-field-story-export.json`

Use this for approved after-event storytelling and simulator-ready records.

The example shows photo length records on legal measuring devices. It allows for both released catches and legal fish kept for food. The competition point is length-based evidence, not weighing fish to win.

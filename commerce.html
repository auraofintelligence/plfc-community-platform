This page prepares the commercial structure without taking payments. Each item can later connect to a Stripe Payment Link, Checkout Session, or Billing flow after committee approval.

Payment architecture

Start simple, grow carefully

The safest first step is Payment Links for clear one-off products. Checkout Sessions come next when the site has forms and member records. Billing is only needed if the club approves automatic recurring renewals.

01

Payment Links

Best for simple memberships, casual comp fees, donation tiers and merch pre-orders.

02

Checkout Sessions

Best when the site needs to create checkout from a form and pass member metadata into Stripe.

03

Billing

Best for true subscriptions, renewal retries and self-service payment updates through the customer portal.

Competition fees

Event checkout can carry useful metadata

Competition pages should record the event name, participant type, member status, mobile number and emergency-contact needs before payment.

Simple version

One Payment Link per competition, with the member entering required details in Stripe custom fields where possible.

Better version

Website form first, Checkout Session second, then confirmation email and committee export.

Future version

Member profile, comp history, waiver status, prize categories and automated wrap-up reporting.
